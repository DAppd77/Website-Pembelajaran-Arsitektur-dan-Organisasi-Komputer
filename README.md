# Website-Pembelajaran-Arsitektur-dan-Organisasi-Komputer
Jelajahi simulasi interaktif untuk mempelajari dan memahami cara kerja CPU, siklus instruksi, hierarki memori, perangkat input dan output (I/O), serta proses perpindahan data antar komponen komputer melalui visualisasi yang informatif dan mudah dipahami.
