# Media Pembelajaran Arsitektur dan Organisasi Komputer (ARSIKOM)

## Project Overview

Project ini merupakan pengembangan media pembelajaran interaktif berbasis web yang dirancang untuk membantu mahasiswa memahami konsep Arsitektur dan Organisasi Komputer (ARSIKOM).

Media pembelajaran ini menyediakan visualisasi dan simulasi interaktif untuk menjelaskan cara kerja komponen komputer, hubungan antarperangkat, serta proses yang terjadi di dalam sistem komputer.

## Objectives

- Memvisualisasikan konsep Arsitektur dan Organisasi Komputer secara interaktif.
- Membantu mahasiswa memahami hubungan dan fungsi setiap komponen komputer.
- Menyediakan simulasi pembelajaran yang mudah diakses melalui browser.

## Features

- Materi pembelajaran ARSIKOM.
- Simulasi interaktif komponen komputer.
- Visualisasi proses kerja CPU dan siklus instruksi.
- Simulasi perakitan komputer.
- Evaluasi pemahaman pengguna.

## Technologies

- HTML
- CSS
- JavaScript

## Design Inspiration

Desain antarmuka (UI) dan sistem pembelajaran website ini terinspirasi dari [freeCodeCamp](https://www.freecodecamp.org/), khususnya dalam penyajian materi pembelajaran, struktur navigasi, dan pendekatan pembelajaran berbasis praktik interaktif.

## Development Notes

- Website dikembangkan menggunakan pendekatan **Vibe Coding**, yaitu metode pengembangan dengan memanfaatkan AI untuk membantu proses penulisan, pengembangan, dan perbaikan kode.
- Pengembangan tetap memperhatikan evaluasi, pengujian, dan validasi kode untuk memastikan fungsionalitas serta akurasi simulasi.
- Gunakan pendekatan modular untuk menjaga performa dan mempermudah proses pengembangan serta pemeliharaan kode.
- Prioritaskan performa karena simulasi dijalankan langsung melalui browser.
- Pertahankan konsistensi desain UI/UX di seluruh halaman dan simulasi.
- Pastikan setiap simulasi sesuai dengan konsep dan spesifikasi teknis perangkat keras yang sebenarnya.
