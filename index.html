Pembelajaran Arsitektur dan Organisasi Komputer

Jelajahi simulasi interaktif untuk mempelajari dan memahami cara kerja CPU, siklus instruksi, hierarki memori, perangkat input dan output (I/O), serta proses perpindahan data antar komponen komputer melalui visualisasi yang informatif dan mudah dipahami.

ketik untuk materi lanjut

    • CPUUnit pemroses pusat: ALU, unit kendali, dan register.
    • Motherboard (MOBO)Papan sirkuit utama penghubung seluruh komponen komputer.
    • RAMMemori utama untuk menyimpan data dan program sementara.
    • Kipas (Cooling Fan)Sistem pendingin untuk menjaga kestabilan suhu komponen.
    • HDDMedia penyimpanan data magnetik berkapasitas besar dan permanen.
    • SSD M.2Penyimpanan berkecepatan tinggi tanpa bagian bergerak pada motherboard.
    • Power Supply Unit (PSU)Unit pengubah arus AC menjadi daya DC untuk komponen.

    ketik untuk materi lanjut

      • Pemasangan CPUSimulasi interaktif 3D langkah pemasangan prosesor pada soket motherboard.
      • Pemasangan RAMSimulasi interaktif 3D langkah pemasangan modul memori pada slot RAM motherboard.
      • Pemasangan GPUSimulasi interaktif 3D langkah pemasangan kartu grafis pada slot PCIe motherboard.
      • Pemasangan SSDSimulasi interaktif 3D langkah pemasangan SSD pada slot PCIe motherboard.
      • Pemasangan Kipas CPUSimulasi interaktif 3D langkah pemasangan kipas pendingin prosesor pada motherboard.
